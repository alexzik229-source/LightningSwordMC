# LightningSword (Paper 26.3 + GeyserMC)

## Build (χρειάζεται JDK 25 + Maven)
    mvn clean package
Το έτοιμο αρχείο: `target/LightningSword-1.0.0.jar` → βάλ'το στο `plugins/` του Paper server και κάνε restart.

## Χρήση
`/lightningsword [παίκτης]` (permission: `lightningsword.give`, default OP)

## Ρυθμίσεις
`plugins/LightningSword/config.yml` (cooldown, max uses, damage κεραυνού, μηνύματα).
